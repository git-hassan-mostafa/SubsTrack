# Web App (`Web/`) — full rules

Short form in AGENTS.md §4. Table mechanics: `docs/ui-patterns.md` → Web tables; page stores: `docs/architecture.md` → Web page stores.

`Web/` — staff desktop web app (React + Vite + React Router + MUI v9 + MUI X), own package, built phase by phase; uses Shared services, stores, `createSupabaseRepositories()` (no offline layer); takes over Expo web's address in the final phase.

- Module folders = SubsTrack layout: `screens/` (`*Page.tsx`), `components/`, `hooks/` (`use*`), `utils/` (`*Look`, `*Icons`); a feature subfolder (`ledger/bill/`) gets the same. Never a loose file in a module root.
- Pages + role rules = ONE list `Web/src/app/routes/appPages.ts` (nav + header title read it). Logout only via `endWebSession()` (`Web/src/state/webSession.ts`); every web-only store in `Web/src/state/` registers its reset there.
- Every list = `DataTable` (fixed `viewKey` → each user's widths/hidden columns/rows per page/row height saved in the browser, `shared/table/tableViews.ts`; `LocalTable` dialog/report grids too — every grid takes a `viewKey`) over a `createPagedStore()` store reading `I*Repository.findPage()` (both impls); the store takes ONE `(query, window)` reader, export = `readEveryPage`. Catalog menus = `useCatalogRowActions`. Customers reads the `customer-status` edge function (filters + sort on the server over every customer).
- Writes go through the Shared slice, then the page patches the returned row (edit, status), adds it (`addRow` on create — top of page 1, total +1; catalog item made inside the sale form joins its Products/Services table too) or re-reads (delete). `patchRow`/`addRow` first ask the store's `fits(row, query)`: row left the filter, or search/filter only the server can judge → mark stale instead of patching. Customers patches an add too (`patchCustomerRow`); a sale save patches every Sales table (`patchSaleTables`, its own owed bump skipped via `runSaleSave`).
- Reopening a page reads nothing — except Audit Log + Money received + WhatsApp messages (`rereadOnOpen`) and a **stale** store: a write outside a table calls `markStale()` (every `ledger.owedVersion` bump marks Customers + Sales via `useMoneyTablesFreshness` in `AppFrame`); a shown table re-reads once. Debts, Wallets, Expenses (Shared stores, both apps) keep their read via a `ReadStamp` (`Shared/src/shared/lib/readStamp.ts`: branch + `ledger.owedVersion` / `products.stockVersion` at read start) — `ensureDebts`/`ensureWallets`/`ensureExpenses` read only when it moved. Every page reads its store via ONE hook `usePagedTable` (also gives `DataTable` its paging props), so a money door never reloads a list itself; toolbar Refresh reads on demand.
- Money in: ONE dialog `CollectDialog` (`Web/src/modules/ledger/collect/`) on Shared `useCollectForm` + `useCollectSubmit` (same as phone sheet); quick pay = Shared `useQuickPay` both apps. Bill: `BillDialog` (`Web/src/modules/ledger/bill/`) on Shared `billView.ts` + `useBillPayments` + `useCorrectPayment` (same as phone bill sheet). Every void taking a reason = `ReasonConfirmDialog`.
- Customer page (`/customers/:id`, `Web/src/modules/customer/customer-detail/`): year as **grid** (taller tiles, default) or **list** (months table), switch top right, over Shared `useCustomerMonthGrid` (same as phone panel); every month door (tap, ⋮ rows, selection, `?quickPay=1`) decided in `customer-payments/utils/monthActions.ts`. Below: Details, To collect (`CustomerToCollectPanel`, = this customer's To collect page dialog: debts + unpaid months), Sales panels; owed row ⋮ = Shared `owedItemActions`, sale ⋮ = Shared `saleMenuItems`, both via Shared hooks the phone panels run.
- Every sale door (receipt, record, edit, collect, send, history, void, bulk) = ONE hook `useSaleDoors` (`Web/src/modules/transaction/sales/`); record/edit in `SaleFormDialog` on Shared `useSaleForm` + `useSaleCart`; a surface holding a charge opens the receipt via `useBillDialog({ onOpenSale })`.
- Every owed-row door (collect, bill, edit, write off, undo, remove, add) = ONE hook `useOwedDoors` (`Web/src/modules/transaction/to-collect/`), shared by To collect page, its `OwingCustomerDialog`, `CustomerToCollectDialog` (Customers table To collect amount link), customer page To collect panel; custom debt add/edit in `CustomDebtFormDialog` on Shared `useCustomDebtForm`.
- Wallets (`Web/src/modules/wallet/`): list + `/admin/wallets/:holderId` + `/my-wallet` (one `WalletDetail`), every receive/close-out door = Shared `useWalletActions`, mode/menus/labels = Shared `wallet/utils/walletView.ts`, filters = Shared `useWalletItemFilters` (phone same).
- Expenses (`Web/src/modules/transaction/expenses/`) = one date window in memory via Shared `useExpensesList` (phone same), `DataTable` paged client-side by `useRowsPage`, re-read on open only when its `ReadStamp` moved; add in `ExpenseFormDialog` on Shared `useExpenseForm`.
- WhatsApp (`Web/src/modules/whatsapp/`): settings + history pages, public `/whatsapp-connect` (outside `SessionGate`); every door = Shared `useWhatsAppActions` (menus `whatsappMenu.ts`, labels/tones `whatsappView.ts`), send = `useSendWhatsAppForm`, connect = `useWhatsAppConnection` + `useEmbeddedSignup` (phone same).
- Dashboard (`Web/src/modules/dashboard/`) = hero + linked tiles from Shared `dashboardView.ts` (phone same). Reports (`Web/src/modules/reports/`) = 7 sections (phone shows Overview + Debts) on Shared `reportsStore` (4 datasets, `ReadStamp`, per-section `views` = filter / groupBy / grain) + pure `reports/utils/analysis.ts` engine + `*View.ts` builders; every number filterable, groupable, drillable to its records; no chart library (plain bars). Detail `docs/features.md` → Web Reports.
- Every row/selection menu = ONE pure Shared fn returning `MenuItem<K>[]` (`Shared/src/shared/lib/menuItem.ts`); apps add icons + handlers only (`toTableActions` web, `toActionMenuItems`/`toSelectionActions` phone), key w/o handler dropped. Page roles = Shared `pageAccess.ts` (`PAGE_ACCESS`), both apps. Every data → colour choice = Shared fn returning a `Tone` (`Shared/src/shared/lib/tone.ts`); admin forms = Shared `<module>Form.ts` (`draftOf`/`canSave`/`input`). Detail `docs/ui-patterns.md`.
- Language (user menu) saved per browser (`web-language`, else browser language); Arabic files lazy-loaded; Arabic MUI core + Data Grid locale `arSD`, date pickers = own `pickersText.ts` + dayjs `ar-latn` (Latin digits). Names in each language's own words = Shared `LANGUAGE_NAMES`; RTL test = `isRtlLanguage()` (all apps).
- Multi-select dropdown filters: `MultiFilterSelect` (`Web/src/shared/table/MultiFilterSelect.tsx`) — see `docs/ui-patterns.md` (Dropdown width).
- `SalesTable` takes its store as a prop → `/customers/:id/sales` runs it on a per-page `createSalesTable(customerId)` store. `BranchesPage` is the reference (`docs/ui-patterns.md`).
