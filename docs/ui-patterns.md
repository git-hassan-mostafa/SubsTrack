# UI Patterns — sheets, cards, headers, styling

Read before touching a bottom sheet, list card, `PageHeader`, `ActionMenu`, or responsive/web layout.

## Styling

- NativeWind classnames everywhere; tokens `src/shared/constants/colors.ts`. Custom `Text` = Cairo for Arabic, system font for English.
- **Weight is a PROP, never a class.** `fontWeight="Medium" | "SemiBold" | "Bold"` on `Text` swaps Cairo face (`Cairo-Medium`/`Cairo-SemiBold`/`Cairo-Bold`), each its OWN family registered in `app/_layout.tsx`. `font-semibold`/`font-bold`/`font-medium` sets numeric weight on plain `Cairo` → synthesized fake bold (muddy, worst on Arabic). Zero weight classes in `src`; grep `font-semibold` = check. `Chip` `md` weight same way.
- RTL via `I18nManager`; language change → full reload (gotcha #5). Web: no reload — `switchLanguage()` (`Web/src/core/i18n/setup.ts`) sets `<html dir>`, theme `direction` + Emotion RTL cache (`app/theme/styleCache.ts`, mirrors every physical left/right) swap in `App.tsx`; arrow icons (back, prev/next, logout) take `sx={flipInRtl}` — MUI icons never mirror. Keyboard avoidance = `react-native-keyboard-controller`, **never** `KeyboardAvoidingView` (#39).
- List rows (customers, users, plans, branches, currencies, products, sales, audit trail, wallet detail) = `<EntityCard>` (`src/shared/components/EntityCard.tsx`): owns wrapper, tap/long-press selection, icon-tile↔checkbox swap, trailing 3-dot menu; card passes `icon`/`iconColor`/`iconBgClassName`, `on*`, optional `dimmed`/`menuLoading`/`disabled` (unactionable row must not flash on press), body as children. Never hand-roll the skeleton.
- **One card surface:** `CARD_SURFACE` (`src/shared/constants/surfaces.ts`, `bg-white border border-gray-100 rounded-2xl`) for every card/panel/section. A **string**, not a component (`PressableOpacity`/`Animated.View` need it too); padding/margins/`overflow-hidden` stay with caller (list row ≠ settings group). `CARD_SURFACE_DIMMED` = off variant, separate constant b/c appending `border-gray-200` gives two conflicting borders w/ no winner (no tailwind-merge). Not this surface: `ConfirmDialog`, `UpgradePromptModal`, `PlanLineCard`, `RemovePlanChoice`, `TierCard`.
- **Chip colours = ONE table**, `TONE_CLASSES` in `src/shared/components/Chip.tsx`: `emerald` cash/paid, `amber` partial/warning, `red` unpaid/overdue/voided, `orange` real-but-lost (written-off, debt), `sky` not-due-yet, `slate` neutral (skipped, inactive, counts), `indigo` plan/stock, `teal` bill kind on debts side, `violet` manual. **No `className` prop** — new colour = new tone, spacing on wrapping `View`. Meaning→tone stays in domain (`kindStyle.ts` `chipTone`, `DebtItemCard` `KIND_STYLE`, `CustomerCard` `FLAG_STYLES`). `size="sm"` card chip (uppercase 10px); `size="md"` detail-sheet hero badge (replaced `CollectionSplitSheet`'s `Pill`). Chips at **bottom of card body**, `mt-1 flex-row flex-wrap items-center gap-1`, never floating above; `CustomerCard` keeps `min-h-[19px]` (statuses arrive after paint; row must not resize).
- **Card text = a ROLE, never colour/size/weight.** `src/shared/components/CardText.tsx`: `CardTitle` (`text-base` semibold gray-900, name), `CardSubtitle` (`text-xs` gray-500, what row IS), `CardMeta` (`text-[11px]` gray-400, when/who/unit), `CardAmount` (`text-base` Bold, `tone="default" | "muted" | "danger"` = normal/voided/unpaid). `className` is **layout only** (`flex-1`, `mt-0.5`, `shrink`). **ONE neutral ramp `gray`**: `slate` removed from `src`, neutral chip tone `gray`, `COLORS` in `colors.ts` is gray.
- Web width: `<ResponsiveContainer>` (`src/shared/components/ResponsiveContainer.tsx`) wraps each screen body / page-sheet form in a centered max-width column; no-op on phones. Centered dialogs cap via inline `max-w-*`. Sheets cap to the **same 768px on web** (`AppBottomSheet` `width` + auto margins on hosting container, #45); native edge-to-edge.
- **Sheets** = `@gorhom/bottom-sheet` v5 on one core `<AppBottomSheet>` (`src/shared/components/AppBottomSheet.tsx`, `BottomSheetModalProvider` in `SubsTrack/app/_layout.tsx`) bridging `visible`/`onDismiss` → `present()`/`dismiss()` (#45). Drag native-only: `SHEET_DRAG_ENABLED` kills both pans on web (#46) → web closes by header button/backdrop. Android Back = `useAndroidBackDismiss`, every variant (Gorhom has no `BackHandler`; Back must never reach router under a sheet). Web: nothing listens to browser Back, it always navigates (a `popstate` close left page dead to clicks, #44). Every sheet `enableContentPanningGesture={false}`; `android_keyboardInputMode` `adjustPan`, never `adjustResize` (#45). Wrappers:
  - `<BottomSheetScaffold>` (`variant="auto"`, content-height): popups `Dropdown`/`DropdownModal` (also `CurrencyInput`'s currency list), `DatePickerInput`, `AsyncEntityPicker`, `ActionMenu`. **Only kind closed by backdrop tap** (#151).
  - **Searchable pickers**: every `Dropdown`/`DropdownModal` over DYNAMIC data (plans, products, services, branches, users, customers, WhatsApp templates) passes `searchable` → search box above the list; fixed enums (status, sort, kind, language, unpaid rule) AND every currency picker (amount field, sale/restock/display currency — the list is short) stay plain. Match = ONE Shared fn `matchesOptionSearch(term, label, sublabel)` (`Shared/src/shared/lib/optionSearch.ts`), web too. Currency rows = Shared `currencyPickOptions()` (code label, name sublabel), both apps.
  - Header dismiss always "Close" (`common.close`), never "Cancel" — it only closes; unsaved data is `dirty` guard's job. `FormSheet` hard-codes it, **no** `dismissLabel`; `Dropdown`/`CurrencyInput`/`AsyncEntityPicker`/`DatePickerInput` match. `common.cancel` only for `ConfirmDialog` and an in-body form leaving a mode w/o closing (sale receipt void-reason form).
  - `<FormSheet>` (`src/shared/components/FormSheet.tsx`, `variant="full"` ≈92%): every form/detail sheet; chrome = handle + title + one dismiss + `BottomSheetScrollView` body in `ResponsiveContainer`. Replaced deleted `SheetModal`. Backdrop tap does NOT close (`dismissOnBackdropPress={false}`, #151). Non-standard bodies (`DebtHistorySheet`, `DebtorDetailSheet`, Wallets collector sheet) use `<AppBottomSheet variant="full">` directly. Owner scrolls body via **`scrollRef`** (`scrollBody.current?.(0)`) — a ref, never a context (#102); stock sheet "Edit entry" uses it. **Detail sheet's secondary actions go in HEADER**: `menuActions?: ActionMenuItem[]` → 3-dot beside dismiss → `ActionMenu`; body keeps only the ONE full-width action the sheet exists for (receipt→send, bill→collect). List frozen on open (`openActions`); a form the menu reveals must be scrolled into view via `scrollRef`. A **form's** footer keeps destructive action under Save (`UserFormSheet`). → #131.
    Body renders one frame after chrome (`useAfterFirstFrame`) — FIXED-snap only, never an `auto` body; always-mounted sheets pass visibility (#51).
  - `<SheetDragArea>` (`src/shared/components/SheetDragArea.tsx`) = header as 2nd drag handle (Gorhom **handle** pan); plain `View` on web (own `Gesture.Pan()`, so `enableHandlePanningGesture={false}` can't reach it, #46). On `FormSheet`, `DropdownModal`, `DatePickerInput`, `AsyncEntityPicker` + the four direct `AppBottomSheet` sheets. **Headers only, never around a list** (handle ignores scroll offset; #45). Exception, body w/ no scrollable: `ActionMenu` wraps whole menu, `activationDistance={12}`.
  - **Slow confirm work → pass `onConfirm`, don't branch on `confirm()`'s result**: `await confirm({ …, onConfirm: async () => { await write(); } })` keeps dialog open + spinning until done — `GlobalConfirmDialog` awaits it, `settle(true)` in `finally` (closes even on throw); old `if (!ok) return; await write()` closed instantly, worked invisibly. Callback in module-level `pendingOnConfirm`, outside immer. Work must not throw past dialog: ledger slice actions catch into `error` (§1.2 rule 10); raw repository call needs own try/catch. Instant follow-up (navigate, clear field) keeps plain `await confirm()`. → #144.
  - **Dirty-form discard prompt wired once**: `AppBottomSheet` `dirty` → every close path via `useUnsavedChangesGuard` → `confirm()`. Form reports `useDirtyForm(form)` / `useDirtyForm({ a, b }, ["ignoreKey"])` (diff vs first render). **Only user-entered fields** — not async data, busy flags, nested-sheet flags, search terms, child-seeded fields (`CurrencyInput` last-used currency, `SaleItemsEditor` cart). Read #54 / #55 first. Guard is in Shared; web `FormDialog` uses it too.
  - Sheet inputs must be `BottomSheetTextInput` (keyboard lift) — `AppTextInput` swaps itself via `useBottomSheetInternal(true)` (no `InsideBottomSheetContext`). Fixed-snap bodies (`FormSheet`/`variant="full"`/`auto scrollable`): plain or Gorhom lists; dual-context bodies take scroll as a prop (`WalletDetailView` `Scroll`); `auto` body = **PLAIN RN list only** (#47). **A PAGING list (`onEndReached`) in a sheet must be Gorhom's** (`BottomSheetSectionList`/`BottomSheetFlatList`) — sheet owns the scroll, plain list reads "at end" from frame one and pages to the bottom unscrolled; hence `CollectionsPanel` swaps list on `inSheet` (cast: generics don't unify). `ConfirmDialog`/`UpgradePromptModal` stay CENTERED RN `Modal`s. New pickers → `BottomSheetScaffold`, forms → `FormSheet`. #44/#45/#47.
  - **Field owns typed text; never wire `value` to form/store state.** `Input`/`SearchTextBox`/`CurrencyInput` use `useTextField` (`shared/hooks/useTextField.ts`): a `value` still awaited is refused as late echo, anything else (prefill, Clear, "full amount" chip, +/- stepper) adopted. Lossy numeric owner passes `expectedEcho`; char filter passes `sanitize`, never in owner's setter. #134.
- `<PageHeader>` (`src/shared/components/PageHeader.tsx`) on every screen, top-right **quick-actions 3-dot**: Collect money / Add customer / Record sale / Add custom debt / Add expense + Batch restock (admin-only) / Money received. UI-only seam like `confirm`: flips `ui` slice (`src/state/slices/ui/`, ephemeral cross-screen UI, ≠ persisted `uiPrefStore`); sheets hosted once by `QuickActionSheets` (`src/modules/quick-actions/`) in `app/(app)/_layout.tsx`. Money received → `CollectionsHistorySheet`; Collect money → `CollectQuickActionSheet` (pick customer, waterfall does rest). Detail `docs/features.md` → The Ledger / Transactions Hub.
  - **Settings = last bottom tab** in `app/(app)/(tabs)/_layout.tsx`, every role (no `href` gate, unlike home/reports/admin). Gear `SettingsButton` gone; `hideQuickActions` hides only the 3-dot; `SettingsScreen` has no back chevron (tab root, #93); dashboard's own header mounts `<QuickActionsMenuButton>` alone.
  - `ActionMenu` always has a header row w/ ✕ right, even w/o `title` (spacer) — non-technical users look for a button; it's a `PressableOpacity` inside the `SheetDragArea` (12pt threshold keeps tap a tap).
  - `ActionMenu` icon colours = ONE table `ICON_COLORS` (`ActionMenu.tsx`), glyph → colour: trash/void danger, cash success, edit/open primary, flash/refresh/pause warning, receipt/document sky, cube teal, time violet, skip slate, whatsapp brand green. `destructive` wins; `iconColor` per-item override; `iconBadge` inherits; `renderIcon` owns its own. Labels uncoloured. Accent tokens `sky`/`teal`/`violet`/`slate`/`whatsapp` in `colors.ts` = icons only.
  - **Row order is a BAND**: `sortActions()` (`Shared/src/shared/lib/actionOrder.ts`) stable-sorts `open`→`money`→`create`→`send`→`manage`→`history`→`status`→`danger` (`delete`/`void` last). Used by `ActionMenu`, `SelectionBar`, `InlineSelectionToolbar`, `PageHeader` `iconActions`; call site sets `group`; in-band caller order kept (export sheet's "this view"/"everything"). Untagged → `manage`, or `danger` if `destructive`. History = last SAFE row (finger expects danger at bottom). Test `tests/suites/actionOrder.test.ts`.
  - **Every row/selection menu decided in Shared**: one pure fn per surface returns `MenuItem<K>[]` (`Shared/src/shared/lib/menuItem.ts`: key, group, labelKey, captionKey, disabled, destructive) — `billMenuItems`, `paymentMenuItems`/`paymentSelectionItems`, `customerMenuItems`/`customerSelectionItems`/`customerStatusItems`, `saleMenuItems`/`saleReceiptActions`/`saleSelectionItems`, `debtItemActions`, `debtorActions`, `catalogRowActions`/`catalogSelectionActions` (`shared/lib/catalogMenu.ts`, 5 catalogs), `userRowActions`/`userSelectionActions`, `stockEntryActions`, `monthMenuItems`, `quickActionItems`. App adds icons (`Record<K, icon>`) + handlers only: phone `toActionMenuItems`/`toSelectionActions` (`SubsTrack/src/shared/lib/menuActions.ts`), web `toTableActions` (`Web/src/shared/table/tableAction.ts`); `run` = map or `(key) => void`; key w/o handler dropped (surface opts out of a door). Status toggles = two keys `deactivate`/`reactivate` (static icons). Tests `tests/suites/rowMenus.test.ts`.
  - **Every data → colour choice decided in Shared**: Shared fns return a `Tone` (`Shared/src/shared/lib/tone.ts`, 9 names; both apps `ChipTone = Tone`) or a tone key; apps map key → colours only. `KIND_TONE` (`collectionKind.ts`), `HISTORY_OUTCOME_TONE` (`debtHistory.ts`), `monthCellTone`/`monthRowStatus`/`monthRowStatusTone` (`customer-payments/utils/monthView.ts`, + months-table figures `monthBillFigure`/`monthPaidFigure`/`monthOwedFigure`/`monthNoteOf`, `isSelectableMonth`), `usageOf` level (`billing/utils/usage.ts`), `allocationRows` (collect preview rows: queue position, status, tone, leaves-owing) + `overByText`/`collectBlocker`/`owedHeadlineKey` (`ledger/utils/allocationRows.ts`), `heldByLabel`/`isHeldByCollector`, `isPaymentVoided`/`coversOtherBills` (`collectionView.ts`). Tests `tests/suites/displayRules.test.ts`.
  - **Admin forms decided in Shared**: one pure `<module>Form.ts` per catalog — `currencyForm`, `planForm` (`withPlanDuration`: multi-month never custom-priced), `serviceForm`/`productForm` (common `core/utils/catalogItemDraft.ts`), `userForm` (one password pair for create + change; owner keeps owner role; one-active-branch staff seed) — `xDraftOf`, `canSaveX`, `xInput`. Phone sheet + web dialog = views; web Save disabled by the same `canSaveX`. Tests `tests/suites/adminForms.test.ts`.
- **Scrollbars: ONE file** `Shared/src/shared/styles/scrollbars.css`, imported by `Web/src/main.tsx` + `Portal/src/main.tsx`: 10px bar, 6px rounded gray-300 thumb (gray-400 hover), clear track, no arrows, overlays nothing, no layout change (just narrower than Windows' 17px). `::-webkit-scrollbar` for Chromium/Safari; Firefox `scrollbar-width: thin` under `@supports not selector(::-webkit-scrollbar)` b/c Chrome 121+ ignores `::-webkit-scrollbar` on elements setting the standard props. `scrollbar-width: none` (MUI scrollable `Tabs`) stays hidden. Phone untouched.

## Web tables (`Web/`)

`DataTable` (`Web/src/shared/table/DataTable.tsx`) for every list; reference `Web/src/modules/admin/branches/screens/BranchesPage.tsx`.

- **Server paging only**: one page of `rows` + filtered `total` from `Web/src/state/createPagedStore.ts`. Sizes 10/25/50/100, default 10 (free Data Grid cap 100). A store takes ONE `(query, window)` reader; export = `readEveryPage(reader, query)`; money pages wrap the read in `withPeriodTotal`. Column sort/menu/filters off — a client sort over one page would lie. Resize ON (every column but ⋮, `resizable: false`; double-click a header edge = grid's own auto-fit).
- **Toolbar view buttons** (`DataTable` only, after Refresh): **Columns** = the grid's OWN columns panel opened from our toolbar (`useColumnsPanel`: `apiRef.showPreferences`, `slotProps.panel.target` = our button, pointer-up stopped while open else click-away closes then the click reopens; hidden on empty state; ⋮ `hideable: false`). **Row height and layout** = `TableViewButton` → `useTableDensity` (`shared/table/tableViews.ts`), ONE choice per user for every table, read by `DataTable` + `LocalTable`; `gridSx(autoRowHeight, density)` scales auto-row padding; menu also holds Reset columns. Saved — see Saved table layout.
- **Toolbar** = ONE `TableToolbar` (`Web/src/shared/table/TableToolbar.tsx`): `SearchField` (owns text, sends after 300 ms) · filters · then tools at row END (top right; left in Arabic): Refresh · columns · view · CSV · `toolbarActions` (e.g. Products "Restock several") · Add. Always DIRECTLY above the grid — `summary` renders above it. A `LocalTable` page list (Debts Debtors/All tabs) uses the same `TableToolbar`; never a hand-built Refresh/Add row (e.g. in a tab bar).
- **Freshness**: store keeps query + rows; `open(branch?)` reads only on first open, header-branch change, or **`stale`**. Refresh (`onReload` = error banner's Try again) re-reads; other devices' changes appear only then. Edit/status write → `patchRow` with the slice's returned row (keeps slot till next read), gated by `fits(row, query)`: `true` patch; `false` (row LEFT filter — branch deactivated under "Active", user moved branch) → stale; `null` (search, or filter row can't answer e.g. last-paid dates) → stale. No `fits` → patches only under default filters + "All branches". `patchRow`/`addRow` return `patched`/`added`/`stale`/`skipped` (a total moves only on in-place patch — Sales). **Add → `addRow`** (top of page 1, total +1, true sort slot on next read; search / later page / `fits` not `true` → stale) on every catalog page + users; product/service made in the sale form (`SaleItemsEditor`) joins its table too. **Delete re-reads** (only server knows gap fill). Customers + Sales:
  - Never re-read on open. `Web/src/shared/table/usePagedTable.ts` (`{...paged.tableProps}` + `paged.search`) re-reads a stale shown table once (`refreshIfStale` never doubles), never while `paused` — Customers pauses during quick-pay loops → N payments = 1 re-read (#117c).
  - Write OUTSIDE a table → `markStale()` (shown: re-read now; hidden: next open). `Web/src/state/useMoneyTablesFreshness.ts` (once in `AppFrame`) maps every `ledger.owedVersion` bump (collect, quick pay, void/correct payment, void bill, write-off + undo, debt add/edit, sale save/void) → `markStale` on BOTH; so no money door reloads itself (would read twice). Customer sales page registers its per-page store while open (`trackCustomerSalesTable`). Hand-marked Customers: skip/unskip (`SkipMonthsDialog`), plan edit (`PlanFormDialog`; Plan column), unpaid rule (`UnpaidRuleSection`); customer rename marks Sales.
  - Customer write (add too) → `patchCustomerRow(id, added)` (`Web/src/state/customersTable.ts`; `fits` = Shared `matchesCustomerFilters`), called by the doors (`CustomerFormDialog`, `useCustomerAdminActions`) so quick action + customer page patch too. Re-reads that ONE customer (row, month bills, skips) + same `getCustomerStatuses` as server — form returns pre-lines customer, untrustworthy for Plan/status. Debt kept (no customer write moves it). New customer → top of page 1 (`addRow`, total + 1) if it fits branch + filters; under search / later page → re-read. Failed read → stale. Delete re-reads.
  - Sale save → `SaleFormDialog` (Record + Edit) calls `patchSaleTables(saved, before)` (`Web/src/state/salesTable.ts`): new → top (`addRow`), edit → `patchRow`, "total sold" += `saleUsd` (`setMeta`), on main Sales (header branch) + each open customer sales page (that customer). Search/filter, or edit moving customer/branch → re-read (via `fits`); total moves only on `patched`/`added`. Customers re-reads (debt moved). Owed bump must not re-read patched tables: `runSaleSave` records `owedVersion + 1` BEFORE the write (signal effect fires before save returns); `markSalesTablesStaleOnOwed` skips exactly it; no-op save clears it; other money writes still mark. Sale **void** re-reads (hand-overs may have paid other sales).
  - Audit Log + Money received pass `{ rereadOnOpen: true }` (no signal yet).
- **Row actions**: ⋮ `RowActionsMenu`, `TableAction`s via Shared `sortActions`. Name cell = link button → Edit; plain row click nothing.
- **Selection**: checkboxes only w/ `bulkActions`; ticks swap toolbar for bulk bar (count, actions, X). Header tick = this page. New rows (page, search, any write) drop selection.
- **Empty**: "no data yet" (title, hint, Add) vs "no results" (hint + Clear filters) via `filtered`; nothing until `loaded`.
- **Errors**: failed read → `ErrorBanner` + **Try again**; failed write → slice error above table (or in open form dialog).

- **Dialog tables** (stock/record history, audit changes, payments on a bill, bills a payment paid): `LocalTable` (`Web/src/shared/table/LocalTable.tsx`), same grid look (`gridBase.ts` + `actionsColumn.tsx`), in-memory rows, no toolbar, footer only >25 rows, `rowTone` greys voided / highlights edited; optional `selection` (`ids`, `onChange`, `isSelectable`), CALLER owns the set so it can widen (months table moves a bundle whole). `DataTable` has `rowTone` too (Money received greys voided). Cells with INPUTS/tick boxes (customer-form plans, Batch Restock, collect bills) → plain MUI `Table` (grid keyboard fights typing). **Never phone-style stacked `List`**: wide dialogs lay facts side by side (figure beside `InfoRows`, fields in a row, payment panel beside bills).

Not tenant data → NOT in `Web/src/state`, logout keeps it. Every cell starts at the start edge — never `align`/`headerAlign: "right"`, money included; only the ⋮ column is centred. No `height: "100%"` on cell content (the flex cell centres it).

## Navigation

- **Every tab stack under `app/(app)/(tabs)/` exports `unstable_settings = { anchor: "index" }`**, even w/o sub-pages — else web refresh/deep link leaves only the nested page, so tab pop-to-top (`state.index > 0`) + `router.back()` no-op. #82.
- **Tab navigator `backBehavior="history"`**: default `firstRoute` sent Back from any tab root to Home, even a **non-admin** to the admin dashboard (`href: null` hides the button, not the route). Stack pops still win (Admin → Plans → Back). #93.
